# 拼图游戏重设计计划

## 设计方向

把现有拼图整理成独立的 **Recon Puzzle / 情报复原** 模式：玩家根据碎片把航拍情报拼回完整图像，在 10 个任务中争取更高评分。保留现有独立入口、图片来源、3×3/4×4/5×5 难度设置和拖放操作。

## 现状问题

- 完整参考图一直显示在棋盘上方，限时提示也显示同一张图，提示几乎没有机会成本。
- 每次移动都加分，鼓励多移动；通关时间奖励与动作效率没有形成清楚的成绩标准。
- 当前界面没有显示已放对多少块，玩家无法快速判断任务进度。
- 拼块托盘按行列规律摆放，关卡之间变化主要来自图片，复玩变化较少。
- 旋转时计时和步数可恢复，但 `PuzzleBoard` 的拼块位置和撤销栈由普通 `remember` 保存，会重置棋盘。

## 新的关卡循环

1. 进入关卡后直接看到拼块棋盘，不常驻显示完整参考图。
2. 玩家拖动拼块到目标位置；保持当前吸附、缩放和撤销操作。
3. HUD 持续显示关卡、剩余时间、总分、步数和已完成拼块数。
4. 每关有 3 次情报扫描；每次短暂显示完整参考图，使用次数计入关卡评分。
5. 超时后可重试当前关；重试重置棋盘和本次倒计时，但累计步数与扫描次数不清零，并计入重试惩罚。
6. 完成关卡时结算分数和 1–3 星；继续后开始下一关并保存累计拼图分数。

## 评分规则

- 以 `gridSize²` 作为标准步数；一步代表一次有效拖动，不论最终放置是否正确。
- 基础分：`100 + level × 25`。
- 时间奖励：通关时剩余秒数 × 2。
- 超出标准步数的惩罚：每步 5 分。
- 每次扫描扣 100 分；每次重试扣 150 分。
- 最低通关分为 50 分；移动拼块时不再直接增加分数。
- 三星：未重试、未扫描，且步数不超过标准步数的 1.5 倍。
- 二星：未重试、最多扫描一次，且步数不超过标准步数的 2 倍。
- 其余通关为一星。

## 视觉与操作调整

- 移除常驻的大幅参考图，腾出棋盘空间；保留限时扫描覆盖层作为情报提示。
- HUD 增加“已归位 / 总块数”和进度条，让完成目标可见。
- 通关弹窗展示星级、步数、耗时、本关得分和累计得分。
- 每关按关卡与网格大小生成稳定的伪随机托盘顺序；同一关旋转或重试布局一致，不同关卡布局变化。
- 保存拼块位置、归位状态和撤销栈，旋转/折叠设备后按新画布尺寸缩放位置并继续当前棋局。
- 英文、简体中文、繁体中文资源保持同步。

## 实施范围

- `PuzzleActivity.kt`：改版 HUD、情报扫描入口和通关结算展示，移除常驻参考图。
- `PuzzleActivity.kt` 的棋盘状态：加入拼块/撤销栈 Saver 与尺寸变化恢复。
- 拼图纯逻辑：加入稳定托盘洗牌和关卡评分计算。
- `values/strings.xml`、中文及繁体资源：同步新文案。
- 不修改 Room 表结构；继续累加保存现有 `puzzleScore`。

## 验收标准

- 默认棋盘不显示完整参考图；玩家主动扫描时短暂显示参考图并减少剩余扫描数。
- 归位进度正确更新；撤销归位后进度回退。
- 移动过程不加分；通关结算产生一次且仅一次的本关分数和星级。
- 重试保留累计步数与扫描使用量，并影响最终评分。
- 同关托盘布局稳定、不同关卡布局不同。
- 旋转/窗口变化后棋盘、撤销能力、计时与步数保持，棋盘位置适配新尺寸。
- Debug 编译通过；本次不运行单元测试。

    我们收集的信息

    我们只在下列用途所必需的范围内收集信息。拒绝授予某项权限不会影响游戏的正常游玩，只会关闭对应的附加功能。

    设备与运行信息

    1. 随机安装标识：首次启动时，本应用会在设备本地生成一个随机 UUID，用于区分不同安装实例。它不包含任何设备硬件标识，也无法反推你的身份。
    2. Firebase 安装标识：由 Firebase SDK 在设备本地生成并保存，用于向 Google 服务建立连接。
    3. 基础使用与运行数据：Firebase Analytics SDK 会在应用启动与会话过程中自动采集应用版本、设备型号与系统版本、语言与地区、屏幕分辨率、会话时长、启动次数等基础运行数据，并发送至 Google。我们没有接入任何自定义埋点，也不会将该数据用于广告投放。
    4. 崩溃日志：崩溃收集默认关闭。仅当你在远程配置中启用了崩溃收集后，应用才会向 Firebase Crashlytics 上报崩溃时的堆栈、异常类型与设备状态信息。

    游戏数据（仅存储在本机）

    下列数据保存在应用私有数据库中，不会上传到任何服务器，卸载应用即随之删除：

    • 空战关卡进度、累计击杀数、难度设置与所选战机；
    • 拼图关卡进度、拼图得分与最高步数；
    • 游戏模式、记录时间戳，以及本排行榜的名次排序。

    玩家名称（可选，仅存储在本机）

    在游戏结束时，你可以自愿填写一个昵称用于本机排行榜展示。该昵称仅写入本应用私有数据库，不会离开你的设备。留空时排行榜会显示为匿名玩家。由于排行榜数据完全保存在本机，我们无法得知、也无法找回你填写的昵称。

    设置的存储

    主题配色、语言、音效开关、震动效果、隐私政策与引导页的完成状态等偏好设置，保存在设备本地的应用私有存储中，不会上传。

    权限说明

    本应用在系统清单中声明了以下权限，以及对应的具体用途：

    • 网络访问（INTERNET、ACCESS_NETWORK_STATE、ACCESS_WIFI_STATE）：用于加载拼关卡背景图片、拉取远程配置，以及与 Firebase 服务通信。
    • 相机（CAMERA）：用于手电筒（含 SOS 闪光求救）功能。发布版本不包含扫码入口。
    • 通知（POST_NOTIFICATIONS）：用于手电筒在前台运行时显示一条常驻通知，这是 Android 系统对前台服务的要求。
    • 振动（VIBRATE）：用于手电筒 SOS 模式下的闪光与震动节奏提示。
    • 唤醒锁（WAKE_LOCK）：用于手电筒 SOS 模式在熄屏状态下保持节奏准确。
    • 读取存储（READ_EXTERNAL_STORAGE，仅 Android 12 及以下）：系统清单中声明了此权限，但应用代码不会请求或使用它。二维码工具通过系统图片选择器读取你主动选中的图片，系统仅向应用授予该图片的访问权限。
    • 联系人（READ_CONTACTS、WRITE_CONTACTS）：仅用于开发调试版本内置的辅助工具；发布版本中该功能不可达，应用不会读取或修改你的通讯录。
    • 电话状态（READ_PHONE_STATE）：在系统清单中声明，但应用代码中并未使用，不会读取设备号码、IMEI 等任何电话相关信息。

    本应用不申请定位权限，不收集你的任何位置信息；不读取短信、通话记录或麦克风，也不会扫描或访问你的整个相册。二维码工具仅在你主动选择图片后读取该图片。

    网络请求与第三方服务

    本应用会向下列域名发起请求，除此之外不会与任何其他服务器通信：

    • peapix.com：获取 Bing 每日壁纸信息，作为拼图关卡的参考图片。该请求会在你的设备与该服务之间传递常规的 IP 地址与 User-Agent。
    • images.cnblogs.com、www.cnblogs.com、raw.githubusercontent.com、github.com、www.baidu.com：加载作者头像、二维码图片与少量示例素材（示例功能位于开发调试版本；默认富文本示例中的图片来自 www.baidu.com）。
    • Firebase（Google）：Analytics 基础运行数据、远程配置参数，以及在启用后的崩溃日志。
    • Google Play：跳转应用商店下载链接时，由系统浏览器完成，本应用不参与该过程的数据传输。

    上述外部服务由各自的运营方独立控制，其数据处理行为受其自身条款约束，我们无法代为控制。

    我们如何使用信息

    1. 在你的设备本地保存游戏进度与设置，使你下次启动时能够继续游戏；
    2. 统计崩溃情况以定位和修复应用缺陷（仅在你启用崩溃收集后）；
    3. 通过远程配置控制应用行为，例如强制更新、功能开关与崩溃收集的启用状态；
    4. 保障应用与服务的可用性、稳定性与安全性。

    我们不做什么

    • 我们不收集你的姓名、性别、年龄、身份证件、精确或粗略位置信息；
    • 我们不出售、不出租、不交换你的任何个人信息；
    • 我们不投放广告，应用中不包含任何广告 SDK，也不会基于你的行为推送广告或营销内容；
    • 我们不使用 Cookie 或网页信标进行追踪；
    • 我们不要求你注册账号，也不收集手机号码、电子邮箱或支付信息；
    • 我们不向第三方共享你的游戏进度、成绩或排行榜昵称。

    第三方 SDK 清单

    • Firebase Analytics（Google）：应用启动、会话与基础运行数据。
    • Firebase Remote Config（Google）：远程配置参数拉取。
    • Firebase Crashlytics（Google）：崩溃日志，默认关闭，需远程开启。
    • Firebase Installations（Google）：本地安装标识与令牌。
    • ML Kit 条形码识别（Google）：仅发布前随应用一同安装的本地识别模型，扫码在设备本地离线完成，不将图像上传至服务器（该入口仅存在于开发调试版本）。

    信息的存储与安全

    1. 你的游戏进度、设置与排行榜数据全部存储在你设备的应用私有空间中（应用私有数据库与私有配置），其他应用无法读取。
    2. 你的设备启用了系统云备份（Android 自动备份）时，上述私有数据可能由操作系统连同其他应用数据一并备份至你登录的系统账号，备份过程由 Android 系统与你的云账号服务商控制。
    3. 拼图关卡图片会缓存于应用缓存目录用于加速加载，可由系统随时回收。
    4. 我们采用 HTTPS 加密保护与外部服务之间的数据传输。

    信息的共享与披露

    除本协议「网络请求与第三方服务」一节所列的 Firebase 与图片服务外，未经你的同意，我们不会向任何第三方披露你的个人信息。我们也不会出售你的个人信息。

    在下列情形下，我们可能需要披露必要的信息：

    1. 遵守适用的法律法规；
    2. 响应司法机关或政府机关依法提出的要求；
    3. 为保护用户、我们自身或公众的人身与财产安全所必需的情形。

    你的权利

    本应用不设账号体系，你对自己的数据拥有完全的控制权：

    • 你可以随时在系统设置中清除本应用的数据，或直接卸载应用，以删除我们保存的全部本地信息；
    • 你可以随时卸载应用，这会使游戏进度、排行榜记录与昵称一并被删除；
    • 对于通过 Firebase 上报的基础运行数据，你可以使用操作系统的「清除应用数据」或在 Google 账号的隐私设置中管理相关数据。

    由于排行榜与昵称仅存在于本机，我们在服务端没有可用于查询、修改或删除你个人信息的对应记录。

    未成年人保护

    本应用不收集任何可用于识别未成年人身份的信息，因此也不会有意收集未成年人的个人信息。我们不会基于你的年龄投放广告或推送营销内容。若你是未成年人的监护人并对本协议有疑问，请与我们联系。

    • 我们可能适时修订本协议的条款，修订构成本协议的一部分。如修订造成你权利的实质减少，我们会在生效前通过应用内的显著提示通知你。

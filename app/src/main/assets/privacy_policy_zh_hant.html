    我們收集的資訊

    我們只在下列用途所必需的範圍內收集資訊。拒絕授予某項權限不會影響遊戲的正常遊玩，只會關閉對應的附加功能。

    裝置與執行資訊

    1. 隨機安裝標識：首次啟動時，本應用會在裝置本地產生一個隨機 UUID，用於區分不同安裝實例。它不包含任何裝置硬體標識，也無法反推你的身分。
    2. Firebase 安裝標識：由 Firebase SDK 在裝置本地產生並儲存，用於向 Google 服務建立連線。
    3. 基礎使用與執行資料：Firebase Analytics SDK 會在應用啟動與會話過程中自動採集應用版本、裝置型號與系統版本、語言與地區、螢幕解析度、會話時長、啟動次數等基礎執行資料，並傳送至 Google。我們沒有接入任何自訂埋點，也不會將該資料用於廣告投放。
    4. 當機日誌：當機收集預設關閉。僅當你在遠端設定中啟用了當機收集後，應用才會向 Firebase Crashlytics 上報當機時的堆疊、例外類型與裝置狀態資訊。

    遊戲資料（僅儲存在本機）

    下列資料儲存在應用私有資料庫中，不會上傳到任何伺服器，解除安裝應用即隨之刪除：

    • 空戰關卡進度、累計擊殺數、難度設定與所選戰機；
    • 拼圖關卡進度、拼圖得分與最佳步數；
    • 遊戲模式、記錄時間戳，以及本排行榜的名次排序。

    玩家名稱（可選，僅儲存在本機）

    在遊戲結束時，你可以自願填寫一個暱稱用於本機排行榜展示。該暱稱僅寫入本應用私有資料庫，不會離開你的裝置。留空時排行榜會顯示為匿名玩家。由於排行榜資料完全儲存在本機，我們無法得知、也無法找回你填寫的暱稱。

    設定的儲存

    主題配色、語言、音效開關、震動效果、隱私政策與引導頁的完成狀態等偏好設定，儲存在裝置本地的應用私有儲存空間中，不會上傳。

    權限說明

    本應用在系統清單中聲明了以下權限，以及對應的具體用途：

    • 網路存取（INTERNET、ACCESS_NETWORK_STATE、ACCESS_WIFI_STATE）：用於載入拼關卡背景圖片、拉取遠端設定，以及與 Firebase 服務通訊。
    • 相機（CAMERA）：用於手電筒（含 SOS 閃光求救）功能。發佈版本不包含掃碼入口。
    • 通知（POST_NOTIFICATIONS）：用於手電筒在前台執行時顯示一條常駐通知，這是 Android 系統對前台服務的要求。
    • 振動（VIBRATE）：用於手電筒 SOS 模式下的閃光與震動節奏提示。
    • 喚醒鎖（WAKE_LOCK）：用於手電筒 SOS 模式在熄屏狀態下保持節奏準確。
    • 讀取儲存（READ_EXTERNAL_STORAGE，僅 Android 12 及以下）：系統清單中聲明了此權限，但應用程式碼不會請求或使用它。二維碼工具透過系統圖片選擇器讀取你主動選取的圖片，系統僅授予應用程式存取該圖片的權限。
    • 聯絡人（READ_CONTACTS、WRITE_CONTACTS）：僅用於開發除錯版本內建的輔助工具；發佈版本中該功能不可達，應用不會讀取或修改你的通訊錄。
    • 電話狀態（READ_PHONE_STATE）：在系統清單中聲明，但應用程式碼中並未使用，不會讀取裝置號碼、IMEI 等任何電話相關資訊。

    本應用不申請定位權限，不收集你的任何位置資訊；不讀取簡訊、通話記錄或麥克風，也不會掃描或存取你的整個相簿。二維碼工具僅在你主動選取圖片後讀取該圖片。

    網路請求與第三方服務

    本應用會向下列網域發起請求，除此之外不會與任何其他伺服器通訊：

    • peapix.com：取得 Bing 每日桌布資訊，作為拼圖關卡的參考圖片。該請求會在你的裝置與該服務之間傳遞一般的 IP 位址與 User-Agent。
    • images.cnblogs.com、www.cnblogs.com、raw.githubusercontent.com、github.com、www.baidu.com：載入作者頭像、二維碼圖片與少量範例素材（範例功能位於開發除錯版本；預設富文字範例中的圖片來自 www.baidu.com）。
    • Firebase（Google）：Analytics 基礎執行資料、遠端設定參數，以及在啟用後的當機日誌。
    • Google Play：跳轉應用商店下載連結時，由系統瀏覽器完成，本應用不參與該過程的資料傳輸。

    上述外部服務由各自的營運方獨立控制，其資料處理行為受其自身條款約束，我們無法代為控制。

    我們如何使用資訊

    1. 在你的裝置本地儲存遊戲進度與設定，使你下次啟動時能夠繼續遊戲；
    2. 統計當機情況以定位和修復應用缺陷（僅在你啟用當機收集後）；
    3. 透過遠端設定控制應用行為，例如強制更新、功能開關與當機收集的啟用狀態；
    4. 保障應用與服務的可用性、穩定性與安全性。

    我們不做什麼

    • 我們不收集你的姓名、性別、年齡、身分證件、精確或粗略位置資訊；
    • 我們不出售、不出租、不交換你的任何個人資訊；
    • 我們不投放廣告，應用中不包含任何廣告 SDK，也不會基於你的行為推送廣告或行銷內容；
    • 我們不使用 Cookie 或網頁信標進行追蹤；
    • 我們不要求你註冊帳號，也不收集手機號碼、電子郵件或支付資訊；
    • 我們不向第三方共享你的遊戲進度、成績或排行榜暱稱。

    第三方 SDK 清單

    • Firebase Analytics（Google）：應用啟動、會話與基礎執行資料。
    • Firebase Remote Config（Google）：遠端設定參數拉取。
    • Firebase Crashlytics（Google）：當機日誌，預設關閉，需遠端開啟。
    • Firebase Installations（Google）：本地安裝標識與權杖。
    • ML Kit 條碼識別（Google）：僅發佈前隨應用一同安裝的本地識別模型，掃碼在裝置本地離線完成，不將圖像上傳至伺服器（該入口僅存在於開發除錯版本）。

    資訊的儲存與安全

    1. 你的遊戲進度、設定與排行榜資料全部儲存在你裝置的應用私有空間中（應用私有資料庫與私有設定），其他應用無法讀取。
    2. 你的裝置啟用了系統雲端備份（Android 自動備份）時，上述私有資料可能由作業系統連同其他應用資料一併備份至你登入的系統帳號，備份過程由 Android 系統與你的雲端帳號服務商控制。
    3. 拼圖關卡圖片會快取於應用快取目錄用於加速載入，可由系統隨時回收。
    4. 我們採用 HTTPS 加密保護與外部服務之間的資料傳輸。

    資訊的共享與揭露

    除本協議「網路請求與第三方服務」一節所列的 Firebase 與圖片服務外，未經你的同意，我們不會向任何第三方揭露你的個人資訊。我們也不會出售你的個人資訊。

    在下列情形下，我們可能需要揭露必要的資訊：

    1. 遵守適用的法律法規；
    2. 回應司法機關或政府機關依法提出的要求；
    3. 為保護使用者、我們自身或公眾的人身與財產安全所必需的情形。

    你的權利

    本應用不設帳號體系，你對自己的資料擁有完全的控制權：

    • 你可以隨時在系統設定中清除本應用的資料，或直接解除安裝應用，以刪除我們儲存的全部本機資訊；
    • 你可以隨時解除安裝應用，這會使遊戲進度、排行榜記錄與暱稱一併被刪除；
    • 對於透過 Firebase 上報的基礎執行資料，你可以使用作業系統的「清除應用資料」或在 Google 帳號的隱私設定中管理相關資料。

    由於排行榜與暱稱僅存在於本機，我們在服務端沒有可用於查詢、修改或刪除你個人資訊的對應記錄。

    未成年人保護

    本應用不收集任何可用於識別未成年人身分的資訊，因此也不會有意收集未成年人的個人資訊。我們不會基於你的年齡投放廣告或推送行銷內容。若你是未成年人的監護人並對本協議有疑問，請與我們聯繫。
